Georgia vs. Gelasio — TL-M-02

Same production colours, type scale, letter-spacing and line-height as src/styles.css, set in Georgia (left) against Gelasio (right) — the SIL OFL, Georgia-metric-compatible serif proposed to replace it across web, iOS and Android. Headings, a moment title, the brand mark, and a numeral sample (Georgia's old-style figures are the detail most substitutes get wrong).

Viewing note: the left column renders true Georgia only where Georgia is actually installed — macOS, Windows, and iOS all ship it natively, so it will render correctly there. Georgia is a proprietary Microsoft font not present on Linux, so on a Linux machine without it installed the left column falls back to whatever generic serif the OS substitutes — view this file on macOS or iOS for the real comparison. Gelasio (right) is embedded in this file directly and renders identically everywhere.
